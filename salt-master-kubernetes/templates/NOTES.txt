{{- if gt (int .Values.agent.replicas) 1 }}

Active-active mode: every replica shares the identical keypair from
agent.masterKeySecretName. Each replica is an independent Salt master
process - a minion needs a live connection to EVERY replica it should be
reachable from (Salt's own multi-master mode, not just failover - see
https://docs.saltproject.io/en/3006/topics/tutorials/multimaster.html).
Point a minion's `master:` config at a list of all replica addresses:
  in-cluster:  salt-master-kubernetes-<N>.salt-master-kubernetes-headless.{{ .Values.namespace }}.svc.cluster.local
  external:    set service.perOrdinal.enabled=true for one NodePort per replica
{{- end }}

{{- if .Values.agent.trustedMinions.enabled }}

Minion acceptance is delegated to salt-key-operator (../salt-key-operator) -
`salt-key -a` will NOT work against this master. Trust a minion by applying
a SaltMinionKey in this SAME namespace ({{ .Values.namespace }}):
  apiVersion: salt.saltstack.io/v1alpha1
  kind: SaltMinionKey
  metadata:
    name: <minion-id>
    namespace: {{ .Values.namespace }}
  spec:
    minionId: <minion-id>
    publicKey: |
      -----BEGIN PUBLIC KEY-----
      ...
      -----END PUBLIC KEY-----

ConfigMap salt-key-operator manages: {{ .Values.agent.trustedMinions.configMapName }}
{{- else }}

Accept a new minion's key the traditional way:
  kubectl -n {{ .Values.namespace }} exec -it salt-master-kubernetes-0 -- salt-key -L
  kubectl -n {{ .Values.namespace }} exec -it salt-master-kubernetes-0 -- salt-key -a '<minion-id>'

{{- end }}
